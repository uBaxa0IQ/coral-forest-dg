# Библиотека источников

`sources.json` содержит библиографические записи, адреса первоисточников и открытых PDF. `download_manifest.json` описывает реально сохранённые файлы: адрес, время загрузки, размер, SHA-256, число страниц и ошибки. `references.bib` создаётся из реестра.

Полные тексты находятся в `pdfs/`, извлечённый текст для поиска — в `text/`. Оригинальные PDF не редактируются. Название файла начинается со стабильного идентификатора источника. Материалы авторских репозиториев для аудита лежат в `upstream/` с отдельной фиксацией происхождения.

```powershell
uv run python tools/fetch_literature.py
```

Повторный запуск проверяет контрольную сумму уже загруженного файла; повторная загрузка без необходимости не выполняется. Статус `downloaded` означает наличие читаемого PDF, а не подтверждение всех утверждений статьи. Отсутствующие полные тексты остаются в реестре с причиной; обход ограничений доступа не применяется.
