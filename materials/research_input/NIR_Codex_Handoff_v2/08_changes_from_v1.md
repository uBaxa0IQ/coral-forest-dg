# Изменения v1 → v2

1. **Точка останова:** v1 поручал только P0/P1 и отдельно предполагал пользовательское утверждение P2. v2 поручает Codex, по возможности, весь цикл P0–P4 с самостоятельным source-only freeze P2 и допустимым финальным test.
2. **Meta-forests:** v1 имел статус `extended_specialized` и ограничивался выяснением наличия кода. v2 делает его **`required_core_method`** с полной попыткой реализации, аудитом математики, тестами MMD/weighting/meta-training и ablations.
3. **Шесть основных методов:** каждый обязан получить независимую проверку оригинальной публикации и исходников, попытку воспроизведения и честный `implementation_status`; не только import check.
4. **Свобода инструментов:** Codex вправе менять пакеты, среды, архитектуру, задачи, budget, strategies source CV, если это оправдано и записано до чтения target.
5. **Новые документы:** `06_method_reproduction.md` и `07_outputs_and_quality.md`; расширены журнал проверок и machine-readable config.
6. **Объём работы:** помимо кода и source пилотов, требуется, если доступно и валидно, полноценная серия экспериментов, статистический анализ, figures/tables и текст результатов НИР.
7. **Сохранили научные ограничения:** строгое source-only DG, запрет target-guided model selection, честная оценка fidelity, парные baselines, обязательная публикация отрицательных результатов, никаких обходов paywalls/licensing.
8. **Материалы `context/` не изменялись:** это исторические источники. Отчёты в них не становятся достовернее от новой версии; Codex проверяет первоисточники.

Никакая версия задания не гарантирует, что все шесть специализированных алгоритмов удастся достоверно воспроизвести. **«Обязательная попытка»** означает полноценную работу с первоисточником, кодом, тестами и объяснённым результатом, а не требование выдумать недостающую математику.
