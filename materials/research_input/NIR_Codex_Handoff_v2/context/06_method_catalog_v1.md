# Рабочий каталог методов Domain Generalization для ансамблей деревьев

**Дата фиксации:** 3 ноября 2026 г.  
**Версия:** v1.0 (по результатам четырёх поисковых итераций; каталог открыт для документально подтверждённых исправлений).  
**Предмет:** Random Forest (RF) и Gradient Boosted Decision Trees (GBDT), классификация и регрессия, табличные данные.  
**Основная постановка:** обучение/выбор модели без доступа к целевому домену; окончательная оценка на ранее невиданном домене.

## Условные обозначения

- **DG подтверждена в обзорах:** материалы предыдущего поиска сообщают об опубликованных экспериментах на невиданных доменах. При глубоком чтении всё равно отдельно проверять отсутствие утечки через подбор гиперпараметров.
- **OOD / смешанная постановка:** есть эксперименты со сдвигом, но не все режимы статьи соответствуют строгой DG.
- **Смежная постановка:** temporal generalization, group-DRO, adversarial robustness, DA и др.; не выдавать за прямое подтверждение DG.
- **Требует проверки:** недостаточно сведений по полному тексту, типу задач, коду или протоколу.

Регрессия не подтверждена. **Открыто:** прочитать полный PDF и приложение, objective, HPO, лицензия/код. https://proceedings.mlr.press/v337/lingjaerde26a.html |

## 3. Реализованные, универсальные и смежные подходы

| Работа / метод | Зачем сохраняем | Почему не относим без оговорок к строгому DG-ядру |
|---|---|---|
| **Time Robust Trees** — Moneda, Mauá, BRACIS 2022 | Временной критерий разбиения дерева классификации | Исходная работа про temporal generalization; отдельную опубликованную оценку *Time Robust Forest* нужно проверить независимо. |
| **MixMax** — ICLR 2025 | Group-DRO / оптимизация смеси исходных распределений с применением к XGBoost | Проверены group-shift сценарии, но не подтверждён самостоятельный strict unseen-target DG эксперимент. |
| **DRO-XGBoost** — Swaroop et al., *Distributionally Robust Feature Selection*, NeurIPS 2025 (Appendix C) | Реализация population-reweighting для XGBoost в классификации и регрессии | Это baseline для задачи robust feature selection; strict DG отдельно не подтверждена. |
| **`dro` для XGBoost/LightGBM (KL/CVaR/χ²)** | Готовые реализации robust objectives | Наличие реализации **не** доказывает эффективность в unseen-domain DG. GroupDRO из этого пакета не обязательно реализован для деревьев. |
| **IRM, V-REx, Group DRO** | Общие концепции инвариантного/робастного обучения | Нет подтверждённой в найденном обзоре специализированной RF/GBDT strict-DG реализации IRM/V-REx; не считать их готовыми алгоритмами дерева. |
| **Stable sample reweighting, Anchor Regression** | Общие математические идеи и возможные baseline | Исходные методы не равны специализированным RF/GBDT алгоритмам. |
| **Spectrally Deconfounded Random Forests** | Модификация критерия регрессии при confounding | Нет прямой проверки переноса на невиданный домен DG. |
| **Robust XGBoost (Sharma et al., UAI 2025)** | Пример изменения split objective бустинга | Adversarial robustness, не domain generalization. |
| **Multi-source distributionally robust RF/learning** — Wang, Bühlmann, Guo | Работа с несколькими исходными моделями | **Unsupervised Domain Adaptation:** использует данные целевого домена. |
| **Boosting for Predictive Sufficiency** — ICLR 2026 | Теория об OOD-поведении стандартного бустинга | Не самостоятельная структурная модификация GBDT. |

## 4. Рабочая матрица четырех направлений

| Направление | Прямые кандидаты для глубокого разбора | Важные дополнительные направления |
|---|---|---|
| **RF — классификация** | IRF, Constrained RF, Meta-forests | O-IRF/HO-IRF (диссертация), DIRF (тип задач уточнить), Time Robust Trees (временной критерий) |
| **RF — регрессия** | **IRF**, MaxRM-RF | DIRF (тип задач неизвестен), Spectrally Deconfounded RF (не DG) |
| **GBDT — классификация** | **Anchor Boosting**; Era Splitting (проверить, что именно реализовано в бинарных опытах) | MixMax, DRO-XGBoost, `dro` (не strict-DG доказательство) |
| **GBDT — регрессия** | Era Splitting, Anchor Boosting | DRO-XGBoost, `dro`, MixMax (не strict-DG доказательство) |

## 5. Открытые вопросы и приоритеты проверки

1. **IRF:** зафиксировать точные формулы для classification и regression, список экспериментов, source-only model selection, исходный код; не повторять ошибку «регрессии нет».
2. **CRF:** полный PDF и приложение, математические constraints, алгоритм и способ настройки, код.
3. **Meta-forests:** точный псевдокод, какие домены используются в meta-training/meta-test/HPO, реальные табличные задачи, код.
4. **MaxRM-RF:** objective и разные варианты, ограничения гарантий, код/лицензия, публикационный статус.
5. **Era Splitting:** математические критерии, фактические реализации classification/regression, отделить DG от DA, корректность выбора гиперпараметров.
6. **Anchor Boosting:** точные формулы для regression/classification, source-only DG отдельно от DA, код и reproducibility.
7. **DIRF:** достать полную главу диссертации, типы задач и результаты.
8. **O-IRF / HO-IRF:** прочитать оригинальную диссертацию, проверить точные критерии и статус публикации.

## 6. Правило дальнейшей работы

Это **зафиксированный рабочий каталог**, а не утверждение абсолютной полноты мировой литературы. Новые элементы добавлять только с первоисточником, явным механизмом, классификацией постановки и отметкой проверки. Отдельно вести **реестр научных публикаций** (включающий датасеты, сравнения и теорию), поскольку число источников не равно числу самостоятельных методов.
