# Воспроизведение IRF

Источник: Liao, Wu, Yan, AAAI 2024, DOI 10.1609/aaai.v38i12.29283. Локальный полный текст: `literature/pdfs/irf.pdf`, формулы 15–22 и §4.3. Прочитаны регрессионная и классификационная постановки; регрессия присутствует в оригинале.

Реализация в `src/nir_dg/trees.py` независимая. Для бинарной классификации оценка разбиения — pooled Gini плюс λ(max I / min I − 1). Отношения I вычисляются по левому дочернему узлу со сглаживанием 0.5/1 из формул 17–19. В регрессии используется pooled MSE плюс λ Var_e(mean_left_e − mean_parent_e), population variance. Bootstrap выполняется отдельно внутри каждой исходной среды, на каждом узле рассматриваются все признаки. Деревья растут до глубины/минимальной численности; прирост обычного impurity не используется как дополнительный запрет положительного penalized loss.

Инженерные решения: до 16 порогов из сетки между наблюдаемыми значениями каждого source-node; минимум 12 объектов в дочернем узле; в регрессии не допускается разбиение с отсутствующей левой группой для активной среды (иначе среднее неопределено). Среды, отсутствующие в родительском узле, не участвуют в его регрессионном штрафе. Эти краевые условия не объявляются точной копией неизвестного авторского кода.

Для AUROC используется доля голосов деревьев. Это оценка ранжирования, не доказанно калиброванная вероятность. Парный контроль — тот же обучатель с λ=0, теми же bootstrap и сеткой. Дополнительно — sklearn RF.

Статус: `independent_reimplementation`; численная репликация таблиц статьи не выполнена. Проверки: нулевой штраф при одинаковых межсредовых эффектах, положительный при различии, domain-wise bootstrap, детерминизм и fit/predict обоих типов задач.
