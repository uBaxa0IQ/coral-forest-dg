# Математические пояснения к второй серии

Этот документ объясняет зафиксированный дизайн; он не меняет frozen grids или критерии выбора. Все реализованные variants перечислены в preregistration.md.

## Что именно меняется в генераторах

Начальные независимые величины Z_j — стандартные нормальные; наблюдаются восемь признаков X_0,…,X_7. Базовая регрессионная зависимость Y=1.5X_0+0.5sin(X_1)+0.7Z_8. Binary label равен индикатору положительного latent Y. Остальные признаки по умолчанию независимый шум. Это компактный известный механизм, а не модель всех табличных задач.

- IID: все домены имеют один закон. Разные domain IDs означают независимые выборки, а не реальные изменения механизма.
- Covariate: X_0=Z_0+δ, X_1=exp(.25δ)Z_1; остальные условные формулы неизменны. P(Y|X) фиксирован, меняется плотность X. Нормальные законы имеют общий неограниченный support; «новый домен» здесь не означает математически непересекающийся support.
- Spurious: после генерации Y заменяется X_2=a_eY+Z_9 в регрессии и X_2=a_e(2Y−1)+Z_9 в классификации. Это антипричинный измерительный признак. Source a∈[.75,2.25], target a∈{−.75,−1.5,−2.25}: меняется направление связи. При всех X это не pure covariate shift. Стабильный механизм через X_0/X_1 есть, но source-only validation может предпочесть ложный признак.
- Concept: коэффициент X_0 равен 1.5+.8δ. Target δ∈{−2.5,0,2.5}; один из коэффициентов отрицателен. Единой оптимальной условной функции для всех доменов не существует. Успех на таком сценарии не следует из общих обещаний invariance.
- Heteroscedastic: средняя latent/regression функция фиксирована, noise scale=exp(.55δ). Меняется P(Y|X), а не только P(X). У binary задачи меняется conditional probability, хотя оптимальная decision boundary остаётся при latent mean=0. Для regression population Bayes MSE в отдельном target равен exp(1.1δ), приблизительно .1920,1,5.2070. Это population risk, не жёсткая нижняя граница каждого конечного sample MSE. Обучатель, не видящий Z_8, не может устранить этот шум. Большой worst MSE сам по себе не доказывает плохую среднюю функцию.
- Missingness: первые три признака независимо маскируются с вероятностью q; source q=.05, target q=.15/.30/.50. Метка генерируется до маскировки. После потери информации P(Y|X_observed) может измениться; это measurement shift, не утверждение о неизменном наблюдаемом conditional.
- Label prior, только binary: Y~Bernoulli(π_e), X_0=.8(2Y−1)+Z_0,X_1=.4(2Y−1)+Z_1. P(X|Y) неизменен, P(Y) меняется. Posterior probability и подходящий порог изменяются, поэтому AUROC, log loss и balanced accuracy отвечают на разные вопросы.

При изменении K диапазон source-параметров сохраняется. В K=4/16 используются общие параметры и вложенные базовые случайные последовательности там, где параметры совпадают. Все K/N/imbalance/seed в одной data replica получают один target draw. Это повышает точность **парных** разностей, но не увеличивает число независимых опытов. Между data replicas RNG streams различны. При дисбалансе размеры суммируются точно в N, порядок геометрических весов случайно переставляется по зарегистрированному seed.

Фиксированный диапазон source-параметра не означает буквально одинаковую pooled distribution: K=4 и K=16 используют разные дискретные сетки и веса опорных точек. H1 относится к числу source mechanisms и плотности их покрытия в этом дизайне. Это не изменение одной метки K при неизменном P(X,Y). В реальных данных при K меняются также identities source-доменов; сравнения описательны. IID-контроль отдельно проверяет K при одном истинном законе данных.

Leave-one-domain source-validation меняет также train fraction и размер heldout sample: при одном общем N train содержит N−N/K, а validation N/K. Поэтому H1 является гипотезой о полном зафиксированном pipeline, включая выбор настройки. Он не изолирует только алгоритм при одной и той же независимой validation выборке. Это особенно существенно при source/target расхождении ranking параметров. Контрасты фиксированной λ в зарегистрированных кривых — диагностический отдельный взгляд, без target-based выбора нового pipeline.

У label-prior генератора class-conditional normals имеют средние ±μ, μ=(.8,.4,0,…,0), и единичную covariance. Идеальный likelihood-ratio ranking имеет population AUROC Φ(sqrt(2||μ||²))=Φ(sqrt(1.6))≈.897 независимо от prior. Это аналитический ориентир DGP, не верхняя граница каждого конечного sample AUROC. Калиброванный posterior добавляет logit(π_e) к 1.6X_0+.8X_1: log loss может ухудшаться при сохранении ранжирования.

Генерация X_spurious из Y задаёт совместный закон пары (X,Y), как в label-conditional/anticausal моделях. Обучатель не получает target y для построения признаков или адаптации: joint target sample целиком генерируется после source selection. Это не обучение на target labels. Но такую DGP нельзя автоматически интерпретировать как любой реалистичный прогноз до наступления исхода.

## Почему быстрый MaxRM эквивалентен исходной конечной задаче

Структура дерева и bootstrap multiset зафиксированы. Пусть l(i) — лист объекта i, I_e — bootstrap позиции среды e, n_e=|I_e|. Для каждого листа l определим a_el=число i∈I_e с l(i)=l, делённое на n_e; b_el=сумма y_i таких позиций, делённая на n_e; c_e=среднее y_i² в I_e. Повторяющиеся bootstrap позиции учитываются столько раз, сколько выбраны.

Тогда точно, без приближения:

R_e(θ)=Σ_l a_el θ_l² − 2Σ_l b_el θ_l + c_e = (1/n_e)Σ_{i∈I_e}(θ_{l(i)}−y_i)².

Минимизируем t при R_e(θ)≤t для каждой среды и t≥0. a_el≥0, поэтому ограничения выпуклые. Dimension зависит от числа листьев, а не числа исходных наблюдений. Pooled leaf means допустимы; оптимальный worst-bootstrap risk не больше worst-bootstrap risk этих исходных листьев, с учётом solver tolerance. Структуры, bootstrap indices и до/после значения проверяются отдельно в аудите.

Это **не** гарантия улучшения target и даже не автоматическая гарантия улучшения worst risk целого усреднённого леса относительно исходного леса: оптимизируются отдельные деревья, ошибки которых могут компенсироваться иначе. Не гарантируется улучшение на исходных уникальных source rows вне bootstrap. Эти различия необходимо сохранять в интерпретации.

## Что изолирует matched control

IRF/CRF сохраняют RNG, bootstrap, структурные параметры, preprocessing и допустимое множество split candidates; меняется штраф. Структура итогового дерева вправе измениться — это результат механизма. У MaxRM структура должна совпасть буквально, иначе leaf-only эффект не изолирован. У Meta совпадают все обученные members и их признаки; меняются только веса. Masked/unmasked — отдельный фактор. У Era общий domain-support restriction остаётся даже при нулевом strength, поэтому внешний sklearn HistGBDT нужен отдельно.

Подбор λ среди нуля и ненулевых значений — практический pipeline с возможностью отказаться от робастности. Если он выбирает ноль, target gain относительно собственного контроля равен нулю по конструкции. Для понимания механизма нужны также заранее зарегистрированные фиксированные grid points; их нельзя выбирать по target и выдавать за source-selected результат.

## Единицы, веса и эффекты

Binary primary score — AUROC, его положительная разность означает улучшение ранжирования. Она не даёт автоматического улучшения calibration. Regression primary risk — MSE в исходных единицах, для сравнений условий делённый на дисперсию полного source этого условия. Нормировка не использует target labels; при N/K сравнениях она может слегка меняться вслед за source sample, поэтому рядом сохраняются исходные MSE/RMSE.

Средний RMSE доменов, корень из среднего MSE доменов и RMSE pooled observations — разные величины. В отчётах macro RMSE означает среднее per-domain RMSE; normalized effect всегда строится из per-domain MSE. Worst target — максимум per-domain MSE/RMSE для regression и минимум per-domain AUROC для classification. Target-домены имеют равный вес независимо от числа rows; это estimand равного домена, не среднего человека/часа.

Сначала усредняются model seeds и target laws внутри data replica. Для эффекта d_r сообщаются среднее и t-интервал: mean(d) ± t_(.975,9)·sd(d)/sqrt(10). Это нормальная аппроксимация по десяти независимым MC повторам. Exact sign test использует только знаки ненулевых d_r, двусторонний binomial p при вероятности .5. Holm контролирует family-wise error среди девяти тестов отдельно H1/H2; зависимость методов не нарушает его применимость. Интервалы не являются одновременно скорректированными и обозначаются как marginal 95% CI.

Holm задан отдельно для двух научных families. Это контроль FWER .05 внутри каждой family, а не единая гарантия .05 для всех 18 тестов вместе.

Sign-test p относится к равновероятности положительного и отрицательного знаков среди ненулевых contrasts, а не является тестом среднего эффекта. При непрерывном распределении это обычно формулируют как тест median-direction; при массе точных нулей здесь явно условное сравнение ненулевых знаков. Mean и t-CI оценивают другую характеристику. Оба вида свидетельств показываются раздельно, без объявления sign p тестом mean=0.

Нет оснований применять этот же MC-интервал к трём пересекающимся source resamples реальной задачи, считать два seed новыми доменами или трактовать пять штатов как случайную выборку независимых стран/популяций. Repeated data draws дают точность внутри выбранного DGP, а не теорему универсальности DG.
