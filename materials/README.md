# Общие материалы исследования

- `docs/` — рабочие документы, постановка задачи, решения, аудит и протоколы.
- `literature/` — единая библиотека: источники, библиография, реестр загрузок и локальные PDF.
- `research_input/` — исходный пакет передачи, сохранённый без редактирования.
- `templates/` — источники оформления и структуры нового отчёта НИР.
- `repository_layout/` — карта старых и новых путей, исходный README и проверка побайтовой сохранности.

Литература и исходные документы общие для НИР и ВКР. Массовые PDF хранятся локально в `literature/pdfs/`; в Git сохраняются библиография, адреса и hashes. Недоступные полные тексты не подменяются другими документами.

Шаблон НИР использует оформление из курсовой `E:/CW/report/`. Из `E:/nir/main/` взят порядок частей и двух основных глав; класс `bmstu` и его preamble не копируются. Происхождение файлов зафиксировано в `templates/provenance.json`.

Исторические документы сохранены побайтово. Для их старых логических путей используется `code/bootstrap_workspace.py setup`; актуальные входные точки — README общего корня и `../nir/index.html`.
