# Материалы ВКР

Отдельное место для текста выпускной квалификационной работы, её графиков, таблиц, приложений, презентации и итоговых сборок.

Общие источники берутся из `../materials/literature/`, постановка и методические документы — из `../materials/docs/`, экспериментальные результаты — из `../nir/results/`, программный проект — из `../code/`. Копии библиотек и результатов сюда не размножаются.

[План подготовки](plan.md) задаёт рабочие разделы. Полный текст и отдельный утверждённый шаблон ВКР пока не создавались; структура НИР автоматически не выдаётся за окончательные требования к ВКР.
