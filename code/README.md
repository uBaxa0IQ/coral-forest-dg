# Программный проект

В этой папке находятся `src/`, `research_versions/`, `tests/`, `tools/`, `configs/`, `runs/`, локальные `data/` и `.venv/`, а также `pyproject.toml` и `uv.lock`.

Из общего корня репозитория один раз создайте локальные совместимые представления:

```powershell
python code/bootstrap_workspace.py setup
cd code
uv sync --frozen --extra research --extra test
uv run python -m pytest -q
```

Проверка замороженных runtime и документов без запуска экспериментов:

```powershell
uv run python bootstrap_workspace.py verify
```

Полная freeze-проверка использует локальные source pools в `data/`; один Git clone не содержит сырых данных и моделей. В текущем перенесённом workspace они сохранены.

Пути `code/docs`, `code/literature`, `code/research_input`, `code/reports` — локальные junction/symlink, созданные bootstrap. Физические документы и литература находятся в `../materials/`, результаты — в `../nir/results/`. Ссылки исключены из Git; копий данных они не создают.

Исторические команды из старых документов теперь выполняются из `code/`. Экспериментальный runtime сохранён побайтово: структура его логического корня остаётся прежней. Это позволяет проверять frozen hashes, не объявляя изменённый код прежней версией. Исторический Git-корень остаётся общим родительским каталогом; в старых опубликованных commits файлы доступны по исходным путям.

Серии завершены. Не запускайте повторно их target-стадии для новых решений: использованные домены уже consumed. Новое исследование требует нового протокола. Перенос папок новых научных результатов не создаёт.

Инструменты обслуживания находятся в `maintenance/`. Полная карта переноса и протокол проверок — в `../materials/repository_layout/`.
