# Шаблон отчёта НИР

[report.pdf](report.pdf) — проверенная сборка каркаса с начальным содержанием и избранными настоящими результатами. Это шаблон для дальнейшего написания, а не законченный текст НИР.

Оформление взято из курсовой `E:/CW/report/`: `preambula.tex` побайтово совпадает с исходным. Собственный `report.tex` добавляет только библиографическое оглавление, скрывает цветные рамки ссылок и подключает необходимые части. Из `E:/nir/main/` взята структура: реферат, содержание, введение, анализ предметной области, методология и результаты, заключение, источники и приложения. Класс/preamble из образца НИР не используется.

Основные файлы:

- `metadata.tex` — ФИО, группа, руководитель, организация и тема. Поля оставлены для заполнения; чужие реквизиты курсовой не перенесены.
- `report.tex` — порядок частей и общие настройки документа.
- `02-essay.tex`, `10-introduction.tex`, `20-analysis.tex`, `25-methodology.tex`, `30-conclusion.tex` — текст работы.
- `35-references.tex`, `40-appendix.tex` — источники и приложение.
- `generated/` — избранные таблицы и численные macros, полученные из существующих v4 артефактов; provenance записан рядом.

Сборка из PowerShell:

```powershell
./nir/report/build.ps1
```

Либо из этой папки: `./build.ps1`. Нужен установленный LaTeX с пакетами preamble курсовой; в текущем окружении сборка проверена с MiKTeX/pdfLaTeX. Сборка выполняется без shell escape; временные файлы находятся в `build/`, итоговый PDF — `report.pdf`.

Проверка отрисовки:

```powershell
code/.venv/Scripts/python.exe code/maintenance/verify_nir_template.py
```

`prepare_nir_template.py` — однократный генератор исходного каркаса. Его повторный запуск перезапишет редактируемые `.tex`, поэтому для обычной сборки используйте только `build.ps1`.

Происхождение шаблонов: `../../materials/templates/provenance.json`. Данные взяты из `../results/tuned_v4/`, а ссылки в библиографии закреплены на историческом Git commit, чтобы перемещение папок их не меняло.
