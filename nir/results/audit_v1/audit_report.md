# Аудит первой экспериментальной серии

Дата: 4 ноября 2026. Проверены реальные локальные артефакты final_v1, frozen Git commit 27a8663956d6578aa2f17687a6bff96e1d8dcef7, конфигурации, CSV, модели, predictions, source data и уже открытые v1 target. Новые holdout для проверки не читались.

Аудит использует отдельную реализацию метрик и проверку артефактов. Выполняет тот же авторский агент; это **не внешнее независимое рецензирование другим исследователем**. Независимость здесь относится к способу пересчёта и проверяемым свидетельствам, а не к личности проверяющего.

## Итог

Численные значения и целостность доступных артефактов подтверждены. Главные научные оговорки относятся к сопоставимости контролей, ограниченной fidelity и силе доказательства исторического запрета target-доступа. Первую серию допустимо использовать как ограниченное exploratory сравнение конкретных реализаций. Нельзя интерпретировать все парные разницы как изолированный эффект одного регуляризатора.

## Проверки, которые прошли

- SHA-256 JSON-протокола совпал; frozen Python code hash восстановлен из Git blobs.
- Хеши четырёх source-CV CSV совпали с зафиксированными.
- Для всех 126 комбинаций независимо восстановлен выбранный source trial; параметры и macro source score совпали с manifest.
- Для 252 строк target-метрик независимо пересчитаны 1008 значений. AUROC — через ранги Mann–Whitney с обработкой ties, AP — через ступени PR на уникальных score, остальные — прямыми формулами NumPy, без вызова исходного score(). Расхождения в пределах 1e−10.
- Для каждого из 126 prediction-файлов проверены row IDs и y по отдельному чтению исключительно старых target. Hospital source/target patient IDs не пересекаются после заявленного исключения.
- Все 126 сохранённых моделей воспроизвели по 256 зафиксированных точек своих старых predictions; сравнивались значения, не только метрики.
- Повторены 42 source fits: первая исходная fold каждого набора, seed=11, trial=0 для каждого применимого метода. Primary scores совпали в пределах 1e−8. Это подмножество, не повтор всех 1050 fits.
- Повторно получены macro summaries с равным весом target-доменов и усреднением по seed; не обнаружены пропущенные или дублирующие final строки.

Машинные доказательства: audit_results.json, metric_recalculation.csv, model_replay.csv, source_fit_replay.csv, source_selection.csv и historical_artifact_hashes.json в этой папке.

## A01 Историческое отсутствие target-доступа доказано не полностью

Код отделяет source-CV от protected evaluator, source fingerprints совпадают, receipts датированы после freeze. Это согласуется с заявленным протоколом. Но нет независимого системного access log, изолированной файловой учётной записи или внешней временной подписи; локальные receipts и timestamps сами по себе не доказывают, что никто не открывал raw target раньше. Хеш фиксирует содержимое, а не внешне удостоверенное время его появления. Абсолютное утверждение «строго доказано отсутствие любого доступа» было бы сильнее свидетельств.

V2: отдельный реестр уже открытых доменов, отдельное хранение нового source, запрет pre-freeze target loader, ledger и immutable manifest с хешами данных/окружения/результатов. Это улучшает проверяемость, но без изоляции ОС не становится криптографической гарантией против произвольного доступа автора.

## A02 MaxRM: две пары выбрали разную структуру

Для gas_turbine_co seeds 23 и 47 MaxRM source-CV выбрал depth=4, paired RF — depth=3. Это корректное сравнение двух независимо настроенных pipelines, но не контроль «та же структура, только другие leaf values». Краткая интерпретация улучшения 0.004333 как чистого эффекта posthoc поэтому недостаточно обоснована. Численные результаты не удаляются и не перенастраиваются.

V2: matched pair получает один structural config, одинаковые bootstrap и tree thresholds; различаются только reoptimized leaf values. Отдельно можно показывать независимо настроенный сильный RF.

## A03 Era paired baseline не является стандартным HistGBDT вообще

Дополнительный source-only стресс-тест на пяти непрерывных случайных наборах выявил max prediction differences 0.89–1.69 между Era(gamma=0,blama=0,vanna=1) и sklearn HistGBDT при одинаковых внешних параметрах. При замене environment IDs на одну группу различие исчезает в этих проверках.

Причина видна в авторском era_splitting.pyx: при have_full_eras=0 кандидат пропускается **до** взвешивания gain; дополнительно при равных gains используется era tie-break. То есть «выключенный» критерий оставляет domain-dependent admissibility. Ранее пройденный простой тест на одном признаке не покрывал это поведение.

Парное сравнение Era с таким контролем остаётся сравнением gain в общем ограниченном search space. Но контроль нужно называть domain-restricted pooled gain; равенство обычному HistGBDT не заявлять. V2 сохраняет его и отдельный действительно обычный HistGBDT.

## A04 IRF regression включает дополнительное ограничение split support

В v1 при λ>0 исключается split с отсутствующей левой группой хотя бы для активной среды; при λ=0 такого запрета нет. Парная разница смешивает штраф и изменение допустимого множества. Это не доказательство ошибки формулы IRF, но мешает изоляции механизма. V2 использует одинаковое явное правило допустимости в обеих моделях; unrestricted baseline сохраняется отдельно.

## A05 Meta matched RF совпадает только по числу деревьев

У Meta лесов min_samples_leaf=5, у pooled matched RF=12. Также отличаются source-specific обучение, sampling ratio, masking и composition ансамбля. Совпадение tree budget не даёт эквивалентного контроля weights/MMD. Историческое название matched означает только matched total trees. V2 нужен uniform-weight контроль **того же списка обученных лесов**, а влияние masking проверяется отдельно при одинаковых исходных RNG-потоках и capacity.

## A06 Fidelity ограничивает область выводов

Meta — явно обозначенная интерпретация недоопределённой статьи; её числа не являются точной репликацией. CRF использует paper objective, но не прошёл R-equivalence. IRF имеет ограниченную threshold grid и выбранные краевые правила. MaxRM использует sklearn-переосуществление MSE-posthoc. Эти ограничения были раскрыты, но в новых выводах необходимо сохранять привязку к конкретным вариантам. «Все шесть методов воспроизведены точно» — недопустимая формулировка.

## A07 Полнота воспроизводимости

V1 проверяет хеш Python-кода, но не включает uv.lock, текущие package binaries, source metadata, выбранные модели и raw predictions в единый pre-evaluation hash. Final runtime inventory записан после серии. Аудит сейчас зафиксировал hashes доступных моделей/predictions; это не превращает их в ранее подписанные файлы. Broad code hash также включал библиографический загрузчик, поэтому исправление имён авторов заблокировало старый evaluator, хотя модельный код не менялся.

V2: экспериментальный code manifest, uv.lock + package versions, source row fingerprints включая time/entity, модельный hash до target, atomic result files, проверки полноты и безопасное возобновление. Библиографические правки отделяются от runtime scope.

## A08 Статистика и мощность

Три seed описывают случайность алгоритма на тех же данных. Их нельзя превращать в новые независимые сдвиги. У Hospital один target; у Gas два последовательных года; станции Beijing коррелируют по времени. Формальных p-values в v1 не было, что соответствует ограничениям. Новая серия должна включать независимые Monte Carlo data replicas в синтетике и заранее заданные контрасты K, N и дисбаланса с контролем объёма данных.

## Решение о первой серии

Сохранить все исходные результаты неизменными. Использовать их как exploratory evidence с приведёнными оговорками. Уже открытые CO/NC/MA, Emergency Room, Huairou/Shunyi, 2014/2015 больше не считаются независимым финальным тестом. Новые решения оцениваются только на новых зарегистрированных holdout. Аудит не дал основания подбирать новые параметры по старым target или скрывать отрицательные результаты.
