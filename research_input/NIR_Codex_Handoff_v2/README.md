# НИР / автономный экспериментально-аналитический пакет для Codex — v2.0

**Дата проектного среза:** 04.11.2026. **Тема:** «Методы обучения ансамблей деревьев решений, устойчивых к сдвигу распределения табличных данных».

## Что изменилось

- Задача Codex — **сквозное выполнение**: независимая проверка науки и исходников → воспроизводимый код → проверки на исходных доменах → заблокированный протокол → финальные DG-эксперименты → научный отчёт с таблицами и графиками. **Не останавливаться автоматически после P0/P1.**
- **Meta-forests включён в обязательное ядро RF-классификации** наряду с IRF и CRF. При отсутствии авторского кода требуется попытка независимого воспроизведения по первоисточнику с отдельным журналом неоднозначностей.
- Codex вправе самостоятельно выбирать библиотеки, архитектуру, альтернативные пригодные данные, бюджет вычислений и порядок действий, если решения **задокументированы, обоснованы и приняты до открытия целевых данных**.
- Не нужно согласовывать каждую техническую мелочь; остановка/обращение к пользователю нужна только при действительно внешнем блокере (учётные данные, платные ресурсы, юридические ограничения, неразрешимая научная неоднозначность, риск некорректного финального тестирования).
- Успех не предполагается заранее: нельзя выдавать неработающий/приближённый метод за точное воспроизведение, а литературные результаты — за собственные.

## Как передать Codex

1. Распаковать папку рядом с будущим репозиторием или поместить в репозиторий в `research_input/`.
2. В новом Codex-чате дать **полный текст** [`03_codex_prompt.md`](03_codex_prompt.md) и прикрепить/указать этот пакет.
3. Codex должен прочитать документы ниже и **самостоятельно выполнить максимальный возможный объём** в среде, где доступны интернет, пакеты, вычисления и нужные учётные данные.
4. Просить не обещания о будущей работе, а **реально созданные файлы, выполненные тесты, логи, измерения и список незавершённого**.

## Неизменяемые научные ограничения

**Strict source-only DG:** данные и статистики целевого домена не используются в fit, преобразованиях, HPO, ранней остановке, подборе доменов/методов или дизайна. Финальная оценка на target допустима только после зафиксированного протокола и только для заранее определённых экспериментов. При ошибках протокола — явная версия исправления и прозрачный отчёт без сокрытия предыдущих оценок.

**Четыре направления НИР сохраняются:** RF × классификация/регрессия и GBDT × классификация/регрессия. Метод используется только там, где его поддержка доказана или независимая реализация корректно обоснована.

**Первоисточники важнее обзоров.** Файлы из `context/` — рабочие материалы, часть содержит исторические противоречия. Доступность шести отдельных подробных разборов статей и полного датасетного отчёта в архиве не подтверждена. При реализации проверять оригинальные PDF, приложения и авторский код.
