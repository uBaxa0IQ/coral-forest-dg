# Рабочая документация НИР

Исходные документы остаются в `research_input/`; эта папка содержит документы, создаваемые в ходе нашей работы. Все научные утверждения должны иметь ссылку на первоисточник и отметку уровня проверки.

- [Постановка и требования](research_scope.md)
- [Журнал решений](decisions.md)
- [Текущее состояние](status.md)
- `methods/` — математические спецификации и проверка воспроизведения.
- `data_audit.md`, `method_audit.md`, `leakage_audit.md` — фактические проверки.
- `preregistration.md` — появляется при реальной фиксации P2, не заранее.
- `protocol_changes.md` — отклонения после фиксации; предыдущие результаты сохраняются.

Даты журналов — Europe/Moscow; машинные временные отметки записываются с часовым поясом.
