# Состояние работ

Первая ограниченная серия P0–P4 завершена 4 ноября 2026: четыре реальные задачи, 1050 расширенных source-CV fits без ошибок, 60 source-only Meta-forests ablations, 15 пройденных тестов. Протокол P2 зафиксирован до target. Завершены все 126 зарегистрированных model/seed запусков, сохранены 252 per-domain оценки и исходные predictions. Численный разбор — reports/research_findings.md.

Это не обещание точного воспроизведения всех авторских статей или окончательного завершения НИР. Exact Meta-forests остаётся blocked; реализована подписанная интерпретация. Библиотека: 58 PDF-файлов для 64 записей (47 различных hashes); шесть недоступных полных текстов перечислены в literature_audit.md. Полная готовность и ограничения — readiness.md. После завершения серии алгоритмы и параметры по target не менялись.

Этот документ обновляется по фактическим артефактам, тестам и журналам запусков. Успешная организация проекта не равна завершённой НИР.
