# Дополнение после source-stage отказов, 5 ноября 2026

Исходная серия попыталась выполнить все 762 задания: 757 завершились, пять остановились до target receipt из-за CLARABEL `optimal_inaccurate` у MaxRM. Самостоятельное принятие такого решения как точного optimum нарушило бы заранее заданное правило. Frozen training runtime, objective, solver, tolerance и grids не меняются. Первоначальные failure JSON и execution summary сохраняются.

Единица сохранения исходного runner — целое задание. Поэтому отказ одного MaxRM fit оставил несохранёнными также семь независимых зарегистрированных pipelines. Дополнение разрешает завершить **только эти исходно зарегистрированные остальные методы**, исключая оба MaxRM grid points в пяти заданиях. Это не замена MaxRM на pooled control и не новая научная настройка по target. Данные, preprocessing, seed, parameters, source folds и выбор конфигураций остальных методов остаются прежними. Код дополнения, его hash и точный список job IDs фиксируются до их target-доступа.

Некоторые соответствующие target draws уже открыты в других исходно зарегистрированных заданиях. Они используются только для завершения той же заранее зафиксированной программы, а не для независимого финального теста новых решений. Новых решений о моделях или гипотезах дополнение не вводит. При последующих изменениях метода эти данные остаются уже открытыми.

Для анализа каждый replica-method cell требует оба seed. Неполные MaxRM cells не усредняются по одному seed. H1 остаётся полным; в H2 у MaxRM regression отсутствует одна полная replica. Этот confirmatory test помечается **не выполнен полностью**, complete-case estimate даётся описательно. При Holm сохраняется исходный размер family=9; отсутствующему тесту для консервативной коррекции остальных соответствует p=1, без объявления его выполненным тестом. Secondary curves показывают число доступных полных replicas, missingness и риск selection bias явно.

Неуспешность solver — часть результата надёжности метода. Дополнение не удаляет отказы, не меняет seed и не пытается получить удобный результат повтором оптимизации.
