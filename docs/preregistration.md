## Зафиксированный объём

126 комбинаций dataset/method/seed: 2 задачи классификации и 2 регрессии, seeds 11/23/47, все зарегистрированные применимые методы и paired controls. RF и GBDT присутствуют на каждой задаче. Meta-forests помечен independent_interpretation; точная репликация не включена под видом готового метода.

Target IDs: ACSIncome — CO, NC, MA; Hospital Readmission — admission_source_id=7; Beijing PM2.5 — Huairou, Shunyi; Gas Turbine CO — 2014, 2015. Роль доменов выбрана до чтения target и описана в data_audit.md.

Параметры выбраны для каждого seed только по macro source-validation primary score. Расширенный source-CV завершён: 1050 успешных fits, все допустимые source folds. У каждой комбинации зафиксированы выбранный trial, параметры, feature names, source fingerprint, target IDs и fidelity. В HPO не участвовали target строки, статистики или метрики.

## Финальные правила

Обучить preprocessing и выбранную модель на полном зарегистрированном source subset; сохранить модель; проверить hash протокола/кода; открыть target через TargetVault; сохранить исходные predictions и метрики по каждому домену. Target не сэмплируется. Предзаданные исключения Hospital и missing outcomes применяются без изменения source. Доступ к каждой комбинации получает уникальный receipt; повторная попытка не считается новым holdout.

Главные метрики AUROC/RMSE, macro с равным весом target-доменов; secondary метрики и стоимость сохраняются. SD по seed не используется как доверительный интервал DG. После открытия target параметры и набор опытов не меняются. Любое отклонение оформляется в protocol_changes.md с сохранением истории.

## Пределы интерпретации

Source ограничен 400 наблюдениями на домен; три seed и небольшие HPO-сетки. Эта серия даёт воспроизводимый ограниченный сравнительный результат, не универсальный рейтинг и не репликацию опубликованных таблиц. Различия собственной реализации CRF/IRF/MaxRM и трактовки Meta подробно описаны в docs/methods/.
