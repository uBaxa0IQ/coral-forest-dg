# Meta-forests Проверка реализации

Полный ансамбль реализован в `src/nir_dg/meta_forests.py`, не заменён обычным RF или диагностикой MMD. Математические ограничения и конкретные трактовки перечислены в [спецификации](meta_forests_math.md).

Проверяются: MMD(X,X)=0, положительное расстояние при сдвиге, устойчивость нормировки больших log-weights, неотрицательность/сумма весов, N(K−1) лесов, раздельность train-source и pseudo-meta-test, наличие допустимых масок, согласование классов при bootstrap без одного класса, нормировка вероятностей, детерминизм.

Параметры `use_accuracy`, `use_mmd`, `feature_masking` позволяют выполнить ablations: ансамбль без обоих компонентов и маски, accuracy-only, MMD-only, masking-only, full. Для полноценного механистического вывода эти ablations должны иметь отдельные журналы реальных запусков; само наличие переключателей не означает выполненного эксперимента.

Парный ресурсный контроль `meta_matched_rf` содержит столько же деревьев, сколько суммарно обучает meta-ансамбль данного fold. Он сравним по количеству деревьев, но не по распределению объектов между лесами и не гарантированно по времени. Дополнительно следует учитывать fit seconds.

Собственная glucose-репликация не заявляется: исходный набор отсутствует. Source-only применение на ACS/Hospital — новый протокол проверки, не воспроизведение опубликованных чисел. Текущий статус полной версии — `independent_interpretation`; точная авторская репликация — `blocked_unverified`.
