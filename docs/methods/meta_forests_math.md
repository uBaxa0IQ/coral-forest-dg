# Meta-forests Математическая спецификация и неоднозначности

Источник: Sun & Kosmas, Meta-forests, PMLR 222:1292–1307, 2024 (ACML 2023). Полный текст `literature/pdfs/meta_forests.pdf`, §3.1, Algorithm 1, Eq. 3, §3.2.

## Подтверждено по полному тексту

Из K исходных сред выбирается одна для pseudo-meta-test; K−1 лесов обучаются по оставшимся средам. Процедура повторяется N раз. Итоговый ансамбль содержит N(K−1) лесов. Используются компоненты accuracy на source-meta-test и MMD между исходными распределениями. После итераций леса собираются в общий взвешенный ансамбль. Описано маскирование признаков, использованных для разбиений в предыдущей итерации той же исходной среды.

Компонент accuracy: exp(accuracy) − exp(1/C). В Eq. 3 произведение предыдущего веса, exp(α W_mmd) и выражения с log, β и W_accuracy. Для MMD приведено центрирование по накопленному среднему с индексами (i−1)(j−1).

## Не определено достаточно для точной репликации

- При i=1 или j=1 записанный знаменатель среднего MMD нулевой.
- Компонент exp(accuracy)−exp(1/C) неположителен при случайном/худшем качестве; логарифм и знак итоговых весов требуют правила, которого нет в псевдокоде.
- Ядро MMD, bandwidth и эмпирическая оценка не специфицированы полностью.
- При смене pseudo-meta-test непонятно соответствие индекса j предыдущему лесу/домену и роль скалярного forest weight внутри обучения следующего RF.
- Не описано поведение маски, когда предыдущий лес использовал все признаки.
- Отдельные решения HPO в опубликованных экспериментах не подтверждают автоматически наш strict source-only протокол.

Подтверждённый авторский код статьи не найден. Поиск по точному названию/авторам и проверка PMLR не дали однозначной ссылки. Это не доказательство отсутствия кода вообще. Другой R-пакет `metaforest` для метаанализа не является этой работой. Обращения к авторам/публичные issue не отправлялись.

## Явная независимая интерпретация

Название в результатах — `meta_forests_interpretation`, статус — `independent_interpretation`. Используется RBF biased MMD² с γ=1/d после fold-local преобразований. Центрирование по ранее измеренным MMD, начальное среднее 0. Положительный вес вычисляется через log-weight: предыдущий log-weight + α(distance−past_mean) + β log(max(exp(accuracy)−exp(1/C), 1e−8)). Это **замена неопределённого update**, а не утверждение точности Eq. 3.

Маскируются использованные предыдущим лесом признаки; при пустом остатке оставляется один признак с минимальной предыдущей важностью. Соответствие предыдущих весов хранится по ID исходного домена. Все полученные леса сохраняются, веса нормируются устойчивым softmax. Настоящий target нигде не участвует.

Эту интерпретацию можно анализировать только как явно обозначенный вариант. Положительные результаты не доказывают эффективность точной авторской реализации. Отдельная точная репликация остаётся `blocked_unverified` до уточнения перечисленных правил.
