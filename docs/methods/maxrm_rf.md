# Воспроизведение MaxRM-RF

Источник: Freni et al., Maximum Risk Minimization with Random Forests, arXiv:2512.10445v2, 11 марта 2026, §3.1 и §4, формулы 7–9. Полный PDF сохранён. Репозитории `francescofreni/nldg` и авторский fork `adaXT` проверены документально; часть загрузок кода завершилась сетевыми ошибками. `nldg` имеет AGPL-3.0, fork adaXT требует отдельной сборки. Их код не копируется в нашу реализацию.

В `src/nir_dg/maxrm.py` независимо реализован MSE-posthoc: каждое дерево sklearn строится на pooled bootstrap, затем значения его листьев оптимизируются по min_theta max_e mean_e[(theta_leaf−y)²] на том же bootstrap. Это выпуклая задача; решается CLARABEL через CVXPY. Centring/scaling y по обучению — обратимое преобразование, сохраняющее MSE-оптимум.

Парная базовая модель использует те же seed, bootstrap, sklearn-деревья и параметры с отключённой переоптимизацией. Тест проверяет неизменность структуры и невозрастание максимального bootstrap-source MSE после решения. Неудача solver вызывает ошибку; молчаливой замены на ERM нет.

Статус `independent_reimplementation`, не авторский adaXT. Оптимизация каждого дерева не равна глобальному минимаксу всего ансамбля. Local/global/tree-weighting, NRW и regret не реализованы в этой версии; соответствующие опубликованные гарантии не приписываются MSE-posthoc. Полная численная репликация статьи не выполнена.
