# Воспроизведение Constrained RF

Первоисточник: Lingjærde et al., UAI 2026 / PMLR 337, `https://proceedings.mlr.press/v337/lingjaerde26a.html`. Полный текст с приложением сохранён в `literature/pdfs/crf.pdf`. Авторский R-код проверен в `Camiling/CRF_code`, commit указан в `literature/upstream_crf.json`.

Независимая Python-реализация минимизирует разложимый функционал H(Y|leaf)+λ1 I(Y;E|leaf)−λ2 H(E|leaf). Вклад дочерних узлов взвешивается их численностями, учитывается улучшение относительно родителя. Энтропия и MI оцениваются по эмпирической таблице «среда × класс», логарифм по основанию 2, нулевые клетки дают нулевой вклад. Третий член препятствует тривиальному разделению доменов по листьям.

Это реализация критерия публикации, не построчный port R. В авторском коде `loss_function` содержит эквивалентный в пределах родительского узла член λ2[H(E)−H(E|split)], но рекурсивное правило остановки и `relax.constraint` требуют отдельного анализа эквивалентности. Здесь применяется явное локальное улучшение paper objective; relaxed-constraint и pruning варианты не реализованы. Bootstrap pooled; используются все признаки, глубина 4 и до 16 кандидатных порогов.

Классификация бинарная. Парный контроль — тот же entropy-обучатель с λ1=λ2=0. Регрессия не заявляется.

Статус: `independent_reimplementation` с описанными отличиями процедуры роста; не `verified_port`. Полная репликация авторских результатов и исполнение R-реализации не выполнены. Оригинальные R-файлы хранятся локально для дальнейшей сверки, не включены в наш код.
